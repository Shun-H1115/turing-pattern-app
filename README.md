# Turing Studio — 反応拡散のアトリエ

Rust と egui/eframe で作ったネイティブのデスクトップアプリです。Gray–Scott 反応拡散モデルが生む模様を、パラメータを変えながら観察・描画できます。実行時の通信、アカウント、Web サーバーは不要です。

## 起動

Windows ではビルド済みの `target/release/turing-studio.exe` をダブルクリックします。

ソースから起動する場合は、このフォルダーで次を実行します。

```powershell
cargo run --release --locked
```

`rust-toolchain.toml` で Rust 1.88.0 を指定しています。Windows のビルドには Visual Studio Build Tools の「C++ によるデスクトップ開発」が必要です。初回の依存関係取得にはネット接続が必要です。OpenGL に対応するグラフィック環境を使用します。

## 操作

| 操作 | 内容 |
| --- | --- |
| プリセット | 迷路・斑点・珊瑚・波紋・細胞。選ぶとパラメータを設定して再生成・再生します |
| 供給率 F / 除去率 k | 反応のバランスを変更。スライダーの数値をクリックすると直接入力できます |
| U / V の拡散 | それぞれの物質の広がる速さを変更します |
| 色のアトリエ | 藍と金・深海・夕映え・翡翠・月白。反転と色の強さも変更できます |
| 一時停止 / 再生、Space | シミュレーションの進行を切り替えます |
| 1 step | 停止中に計算を1ステップ進めます |
| 左ドラッグ | 物質 V の種を描きます。停止中も描けます |
| 右ドラッグ | U=1、V=0 に戻します |
| 初期状態へ、R | 同じシード・現在の設定で0ステップから再開します。再生/停止状態は維持します |
| 新しい種 | シードを変えて再生成します。再生/停止状態は維持します |
| 解像度 | 128・256・384・512。変更すると再生成します |
| PNG を保存 | 現在の模様を計算解像度で保存。画面に保存先の絶対パスを表示します |

起動時とプリセット選択時は、模様が見えるまで最初の1,600ステップを高速に進めます。その間も操作できます。任意のパラメータで模様が維持されるわけではありません。均一になった場合はプリセットを選び直してください。

保存先は**実行ファイルと同じ場所に作られる `captures` フォルダー**です。保存できない場合は画面にエラーを表示します。ファイル名は一意に生成し、既存画像を上書きしません。PNG の Description メタデータにはパラメータ、シード、ステップ、配色情報を記録します。ブラシ操作の履歴は保存しないため、画像メタデータは編集状態の復元用ではありません。アプリを閉じるとシミュレーションと設定はリセットされます。

## 数値モデル

```text
∂U/∂t = Du ∇²U − UV² + F(1 − U)
∂V/∂t = Dv ∇²V + UV² − (F + k)V
```

9点差分ラプラシアン（中央 −1、上下左右 0.2、対角 0.05）、前進 Euler 法（Δt=1）、周期境界を使用します。濃度を [0,1] に制限し、UI の入力範囲も制限しています。科学的な定量解析用ではなく、模様の探索・可視化向けです。色は V の濃度を 2.8 倍して [0,1] に制限した値に対応します。

計算は CPU、画面描画は OpenGL です。各フレームの計算は約12msを目安に打ち切り、操作への応答を保ちます（最低1ステップ）。速度はフレームごとの最大ステップ数なので、実際の進行速度はCPU・解像度に依存します。日本語はOSのフォントを読み込み、フォントファイルを配布物には含めません。Windowsで検証しており、macOS/Linuxでの動作は未検証です。

参考: [Gray–Scott モデル（MIT）](https://groups.csail.mit.edu/mac/projects/amorphous/GrayScott/) / [eframe 0.32.3](https://docs.rs/eframe/0.32.3/eframe/)

## 検証・開発

```powershell
cargo fmt --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo build --release --locked
```

GUIなしで既定の迷路パターン（256×256、seed=42、2,400ステップ）を生成できます。出力先に既存ファイルがあると失敗します。

```powershell
target\release\turing-studio.exe --render-preview preview.png
```

コード構成: `src/simulation.rs` が数値計算、`src/palette.rs` が配色、`src/export.rs` がPNG出力、`src/main.rs` がデスクトップUIです。
